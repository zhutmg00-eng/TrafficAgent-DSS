# TrafficAgent-DSS：技术方案与系统实现设计

本文档详述 **TrafficAgent-DSS（基于交通仿真智能体的城市交通拥堵治理决策支持系统）** 的系统设计、算法原理与实现路线，供团队技术研发与说明书撰写参考。

---

## 1. 业务背景与问题定义

### 1.1 核心痛点
1. **经验驱动 vs 动态变化**：传统城市交管严重依赖交警人工经验，面对突发事故或反常流量波动时，策略调整往往滞后于拥堵扩散。
2. **黑盒算法不可解释**：近年来基于深度强化学习（DRL）的自适应控制模型难以解释“为何在此时切绿灯”，且泛化能力差，交管调度人员不敢直接采纳。
3. **缺乏推演验证工具**：现存系统多数是“先实施、后看效果”，缺乏低成本的快速“事前推演（What-If 分析）”手段。

### 1.2 系统目标
打造一套**具备人机交互、领域推理、沙盒推演与可解释报告**的智能决策辅助系统。实现：
- **快速归因**：从路网多点感知数据中秒级锁定拥堵核心瓶颈与成因。
- **自主调策**：利用专业交通工程工具（Webster、绿波、诱导）自动构思多种复合治理预案。
- **数字孪生推演**：利用 SUMO 在后台快速推演不同方案，输出量化评价。
- **决策报告与交互**：通过可视化图表和文字向交管工程师推荐最优解与推演依据。

## 3. 关键算法与技术实现

### 3.1 拥堵诊断与归因智能体 (Diagnosis Agent)
- **输入**：路网检测器数据（车道占有率 $O_i$、瞬时车速 $v_i$、排队长度 $Q_i$、到达率 $\lambda_i$）。
- **推理逻辑**：构建时空关联拓扑图。
  - 若下游车道占有率 $> 85\%$ 且速度接近 0，则判定为**溢流阻塞型拥堵**；
  - 若单进口道左转排队超过拓扑库容量，则判定为**车道级相位不平衡**；
  - 若特定路段速度骤降至 0 且持续不散，则判定疑似**突发事故/施工占道**。
- **输出**：结构化拥堵归因描述（JSON）。

### 3.2 交通工程增强工具箱 (Tool-Augmented Modules)
智能体并非凭空臆测配时，而是调用标准交通工程算法作为推理基础：
1. **Webster 最佳周期与绿信比计算**：
   $$C_0 = \frac{1.5 L + 5}{1 - Y}$$
   其中 $L$ 为总损失时间，$Y = \sum y_i$ 为各关键相位流量比之和。智能体根据实时检测的流量比快速计算科学基准周期。
2. **干线动态绿波协调**：
   根据干线设计车速 $V$ 与相邻交叉口间距 $S_{ij}$，自动计算理想相位差（Offset）：
   $$\Delta \phi_{ij} = \frac{S_{ij}}{V} \pmod C$$
3. **动态诱导重路由（Rerouting via VMS）**：
   通过 TraCI 调整进入拥堵走廊前分流节点的车辆转向概率，向平行旁路引流 $\alpha \in [10\%, 40\%]$ 的非刚性出行车辆。

### 3.3 仿真沙盒推演闭环 (Simulation-in-the-loop)
1. **基线推演（Do-Nothing）**：保持当前现状运行 $\Delta T = 600$ 秒，记录各指标基线值。
2. **方案 A（局部优化）**：执行自适应信号优化，运行 $\Delta T$ 秒。
3. **方案 B（系统协同）**：执行信号优化 + 跨节点绿波 + 诱导分流，运行 $\Delta T$ 秒。
4. **指标提取器（Evaluator）**：
   - 提取全网与瓶颈路段性能：
     - **平均延误时间（Delay, s/veh）**
     - **最大排队长度（Max Queue, m）**
     - **网络吞吐量（Throughput, veh/h）**
     - **燃油消耗与碳排放（CO2 Emissions, kg）**
5. **智能体反思微调（Reflexion）**：
   若方案推演显示指标改善不及预期（例如旁路发生次生拥堵），智能体回溯下调分流比例，重新发起一次快速校验。

## 4. 评价指标体系

系统输出标准化的 A/B 评测对比表，供前端决策看板与论文使用：

| 评估维度 | 核心指标 | 计算方式 / 物理意义 | 目标预期 |
| :--- | :--- | :--- | :--- |
| **通行效率** | 平均行程延误 (Delay) | 车辆实际行程时间与自由流时间之差 | 降低 $\ge 25\%$ |
| **空间瓶颈** | 最大排队长度 (Queue) | 交叉口各进口道等待车辆队列最大值 | 缩短 $\ge 30\%$ |
| **容量利用** | 瓶颈断面放行量 (Flow) | 单位时间内通过瓶颈关键断面的车数 | 提升 $\ge 15\%$ |
| **运行平稳** | 行程时间方差 (Variance) | 反映路网运行可靠性与车速离散度 | 降低 $\ge 20\%$ |
| **绿色低碳** | 碳排放与能耗 (Emission) | 基于 SUMO HBEFA 排放模型测算 | 降低 $\ge 10\%$ |

## 5. 交互原型界面规划 (FastAPI + 现代化解耦 Web 决策大屏)

- **架构设计**：采用**前后端解耦（Decoupled Architecture）**生产级架构，后端基于 **FastAPI** 提供高并发异步 RESTful API，前端基于现代化响应式单页应用（HTML5 / ECharts 5 / 深浅双模主题），支持毫秒级图表自适应重绘与交互响应。
- **模块 1：走廊实时态势感知区**
  - 核心路段车速、排队长度、断面占有率与旁路空闲容量实时看板，集成突发占道警情脉冲告警。
- **模块 2：智能体思维链诊断终端 (CoT Terminal)**
  - 极客风格终端界面，逐层展示态势感知、空间排队、成因归因、蔓延风险与旁路核查等完整链条，透明可溯。
- **模块 3：候选方案构想与多工具协同**
  - 基线（Do-Nothing）、方案 A（Webster 自适应配时）、方案 B（Agent 协同：Webster + 绿波协调 + VMS 诱导分流）卡片式直观比选。
- **模块 4：数字孪生推演与五维效能看板**
  - 交互式五维成效雷达图（通行效率/空间治堵/容量释放/运行平稳/绿色低碳）与 600 秒推演期瓶颈排队消散时序曲线。
- **模块 5：格式化决策简报与一键导出**
  - 自动生成符合交管规范的决策建议书，支持一键复制简报与导出 Markdown / PDF 报告。
